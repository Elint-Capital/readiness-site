Your files stay with you

The Lender performs every lender function; this software produces findings for the Lender's own review.

Where it runs

On a server the Lender controls: its own cloud account or its own premises. Files are encrypted with keys the Lender holds. The reading model runs inside the same account. Uploaded files are deleted after a number of days the Lender sets.

What can leave, and only if the Lender says so

Counts and finding numbers, so the partner can see how many files were reviewed. Never a borrower's name, number or document. Social Security and tax ID numbers are masked on every page and in every printout.

For the vendor-management file

A due-diligence packet is prepared: the security description, the penetration test, the business-continuity plan, insurance certificates, a completed SIG Lite questionnaire, and the SOC 2 report or its dated plan. The report is the Lender's own quality-control work paper, the same as a mortgage QC audit.

This Readiness Review is a software tool the Lender uses to assist its own review of a loan file. It does not determine eligibility, creditworthiness, guaranty coverage, or compliance; it makes no representation to, and is not reviewed or endorsed by, the U.S. Small Business Administration. Under 13 CFR 120.180 the Lender remains solely responsible for compliance with SBA Loan Program Requirements in effect at the time of each action. Findings are indicators for the Lender's judgment, not legal, accounting or credit advice. Citations refer to SBA documents by title, version and effective date; the Lender verifies the current text.
